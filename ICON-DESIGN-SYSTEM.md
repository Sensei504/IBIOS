# IBIOS icon design system

- Use `lucide-react` only; do not mix icon packs or use emoji as interface icons.
- Use outline icons with a consistent stroke (typically `strokeWidth={1.8}` to `2`).
- Navigation icons: 16–18px. Inline actions: 15–17px. Empty states: 22–28px. Avoid decorative icon clusters.
- Every icon-only button requires an accessible label and visible focus styles.
- Prefer icons for recognizable actions, status, and navigation. Do not prefix every card title with an icon.
- Use the same icon for the same action across screens and rely on text for ambiguous controls.
